Репозиторий с лабораторными работами по дисциплине «Математическая статистика».

## Лабораторная работа № 1

Файл [`lab_01/lab_01.m`](lab_01/lab_01.m) выполняет:

- поиск минимума, максимума и размаха выборки;
- расчёт выборочного среднего `q` и исправленной выборочной дисперсии `S²`;
- группировку в `m = floor(log2(n)) + 2` интервалов;
- построение гистограммы вместе с плотностью нормального распределения с параметрами, оценёнными по выборке;
- построение эмпирической функции распределения вместе с соответствующей нормальной функцией распределения.

Полученные в отчёте значения: `n = 120`, `min = 6.81`, `max = 12.41`, `R = 5.60`, `q = 9.487`, `S² = 1.217`, `m = 8`.

## Лабораторная работа № 2

Файл [`lab_02/lab_02.m`](lab_02/lab_02.m) при уровне доверия `γ = 0.9`:

- вычисляет точечные оценки среднего и исправленной дисперсии;
- строит доверительный интервал среднего по распределению Стьюдента;
- строит доверительный интервал дисперсии по распределению χ²;
- показывает, как оценки и границы интервалов изменяются при увеличении объёма подвыборки.

Итоговые значения для полной выборки: `μ̂ = 9.4872`, `S² = 1.2173`, доверительный интервал для среднего — `[9.3202; 9.6541]`, для дисперсии — `[0.9959; 1.5279]`.
